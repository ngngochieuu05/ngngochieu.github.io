⚠️  ĐỔI MẬT KHẨU ADMIN NGAY!
────────────────────────────────────────────────────────

1. Vào phpMyAdmin trên hosting
2. Chọn database → Bảng admin_users
3. Chạy SQL:

   UPDATE admin_users 
   SET password_hash = '$2y$10$[HASH_MỚI]' 
   WHERE username = 'admin';

4. Tạo hash mới tại: https://bcrypt-generator.com/
   hoặc tạo file PHP tạm:

   <?php
   echo password_hash('MatKhauMoiCuaBan', PASSWORD_DEFAULT);
   ?>

5. Copy hash và dán vào SQL trên


═══════════════════════════════════════════════════════
  ❌ XỬ LÝ LỖI THƯỜNG GẶP
═══════════════════════════════════════════════════════

LỖI: "Connection failed"
────────────────────────────────────────────────────────
→ Sai thông tin database trong config.php
→ Kiểm tra lại DB_HOST, DB_NAME, DB_USER, DB_PASS

LỖI: "Table doesn't exist"
────────────────────────────────────────────────────────
→ Chưa import database.sql
→ Làm lại BƯỚC 2

LỖI: Form không gửi được
────────────────────────────────────────────────────────
→ Mở F12 (Developer Tools) → Console
→ Kiểm tra lỗi JavaScript
→ Xem tab Network → Xem response từ submit_contact.php

LỖI: 404 Not Found cho admin
────────────────────────────────────────────────────────
→ Kiểm tra đường dẫn:
   ✓ Đúng: yourwebsite.com/backend/admin/login.php
   ✗ Sai: yourwebsite.com/admin/login.php

LỖI: 500 Internal Server Error
────────────────────────────────────────────────────────
→ Kiểm tra error_log trong cPanel
→ Thường do sai cú pháp PHP hoặc thiếu extension
